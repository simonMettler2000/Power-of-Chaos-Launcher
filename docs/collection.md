# Read-only collection statistics

The launcher reads one selected stock system.dat, not decks or three invented separate collections. It never writes saves, repairs checksums, changes save identity or updates CommonDir/flcrc. The optional save path is ordinary launcher preference data. Ambiguous automatic discovery requires an explicit choice.

On Windows, automatic discovery reads the game's configured CommonDir, including the per-user registry VirtualStore used by legacy games. A virtualized value shadows the corresponding machine value; the 32-bit physical path includes WOW6432Node on 64-bit Windows. Configured locations take precedence over guessed installation siblings and the default Common folder. A missing configured save stays unavailable instead of showing an unrelated old save's counts. Without configured locations, bounded fallback paths also check Windows file virtualization. No registry key or save location is changed.

Per-game availability uses each game's own bin#\card_pack.bin and bin#\card_id.bin resources. Each has 1,115 little-endian UInt16 slots. Apply cumulative masks 1, 3 and 7 for Yugi, Kaiba and Joey respectively: 155, 466 and 771 distinct types. Older archives' future-game bits are incomplete, so Joey's full pool must come from Joey. Internal save slots are not external card IDs or contiguous 155/466/771 ranges. External card ID zero is valid.

The reader counts slots with nonzero quantity, filters through that game's pool, and unions external identities across readable games. Copies are not added to the unique total. Inconsistent identity tables and unsupported pools fail closed. Missing card data leaves that row unavailable and labels the combined count as partial. The maximum across the supported games is 771.

Only the stock 5,062-byte encrypted format is accepted. Its outer checksum intentionally covers encoded offsets 4 through 4,495; 562 nine-byte blocks decode to 4,496 bytes. Canonical modulo-299 fields, payload signature/magic and the inner UInt16 checksum are required. Quantity is the low byte at decoded offset 0x14 + 2 * internalSlot; deck flags in the high byte do not confer ownership. The registry identity checksum is not a decryption key and is not modified.

Format references: the authors' [save codec and analysis](https://github.com/hiroshil/YGO_SystemDat_Editor), [original codec](https://gist.github.com/ideka/af4bc83f6dceac7d8314e18e83f69499), and [shared-save handler](https://github.com/markomavrinac/yugioh_poc_save_handler). These describe the format; this repository contains an authored read-only implementation and synthetic fixtures, not copied save files, card tables or upstream modules.

Archive reads share the existing bounded in-memory resource reader with portraits. Only named resources are read, with entry/payload bounds and cancellation. Save selection rejects linked ancestry, reads a bounded read-only snapshot, and never extracts game content to disk. Refreshes cancel superseded requests so stale results cannot update a removed game or closed window.

Verification covers independently calculated small codec vectors, an independently encoded synthetic save, both checksums, unsupported/noncanonical encodings, sparse internal slots, external ID zero, deck flags, cumulative pools, deduplication, missing/ambiguous files, cancellation, changed saves and UI refresh/persistence. Optional installed tests use synthetic ownership against real archives read-only; they do not require or modify an actual save and never start a game. Availability of an actual user's save is separate from these checks.

Each game panel expands into owned and missing cards. Native card images come from that installation's own `mini\list_card.txt` and its referenced BMP resources. List record order is the internal save slot; card IDs are read from the forward identity table, not used as filename indexes. Cards stay at their original 49/50 × 72 logical pixel size, with no click preview or enlargement. Missing cards are dimmed. Hover text gives the localized card name, copy count and first game where the card is available, determined from the lowest availability bit. No HD card mod is needed.

Artwork is loaded only for expanded panels, using one bounded archive index per load. The filename table is limited to 128 KiB, individual images to 16 KiB, and a mini batch to 16 MiB. Unsupported or missing images retain placeholders without changing ownership counts. The reader preserves every card pixel as opaque, including green; portrait transparency processing does not apply to cards. Collapse, replacement and window close cancel pending loads and release card bitmaps. Unknown ownership leaves the gallery empty rather than marking every card missing.

The saved Language selector controls both the launcher interface and the card names. The existing `CardLanguage` preference key is retained for compatibility. Card names use one of six whitelisted `bin#\card_name{language}.bin` resources from each installation. Every table contains 1,115 fixed 64-byte, NUL-terminated, zero-padded records indexed by the same internal slot. Western languages use Windows-1252; Japanese uses Windows codepage 932. Strict decoding preserves accents, ligatures and Japanese characters. Names are read in memory with a 128 KiB resource limit, never bundled, downloaded, extracted or used as identities. Legitimate duplicate names remain separate cards. Blank or unavailable names retain the external ID fallback; Kaiba's stock Italian table has one eligible blank entry. Installation-specific differences are preserved. Language changes cancel superseded loads, and failed preference saves restore the previous interface language, selection and displayed names.

Interface translations are authored launcher resources. They update existing controls through live bindings; view models retain their raw English statuses and render them in the active language. Known formatted diagnostics preserve captured paths and game titles. Unknown operating-system diagnostic details stay intact for copying/debugging. Power of Chaos, game titles, native card-name data, file paths and command values are never translated by word substitution. A language is applied only after its preference-save outcome is known; a failed save restores the prior language and restarts expanded galleries.
